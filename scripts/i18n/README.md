# Перевод интерфейса

Ключ перевода — русский текст: `tr('Закрыть')`, с подстановками `tr('Задач: {{n}}', { n })` (`apps/web/src/lib/tr.ts`).
Словари: `apps/web/src/locales/{en,ka}/src.json`. Нет перевода — показывается русский.

Новая русская строка в коде → оберните в `tr()` → `node scripts/i18n/extract.cjs` покажет непереведённые ключи в `work/chunks/` →
переводы пишутся строками `индекс~~English~~ქართული` в `work/tsv/*.tsv` → `node scripts/i18n/merge.cjs`.
Справочные тексты базы (роли, статусы, сигналы…) — строки `русский~~English~~ქართული` в `work/data/*.tsv` → `node scripts/i18n/merge2.cjs`; шаблоны с `{{p1}}` сопоставляются по частям.
`codemod.cjs --apply` оборачивает русские строки автоматически (одноразово), `leftover.cjs` показывает необёрнутые.
