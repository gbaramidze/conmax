# Модели зданий (IFC)

Исходные модели от архитекторов для раздела «3D-модель» проекта. Хранятся сжатыми (`.ifczip` — обычный zip с одним `.ifc`):
GitHub не принимает файлы больше 100 МБ, а IFC отеля весит 426 МБ (в архиве — 70 МБ). Несжатые `.ifc` в `.gitignore`.

| Проект | Файл | Откуда | Примечание |
|---|---|---|---|
| RTG1 | `RTG1/ROTANA - For Pontus - 202607 city hall.ifczip` | ArchiCAD 28, IFC2X3, мм, 26.11.2026 | 36 этажей; зон помещений (IfcSpace) нет — ждём выгрузку с зонами |

Как загрузить в проект: страница «3D-модель» → «⋯ → Загрузить новую версию» → выбрать `.ifczip` (с компьютера, перевод в браузере ~30 с).
Из командной строки: `node scripts/model/ifc-to-glb.mjs "models/RTG1/….ifczip"` — получится `.glb.gz`, его тоже можно загрузить на странице.
